# ステージ5 チュートリアル引き継ぎ

## 目的

ステージ5を固定マップのチュートリアル（訓練場）に変更する。初代『トゥームレイダー』の館のトレーニングのように、右へ一本道で進みながら、区間ごとに一つずつ体験する。体験する内容は、敵のパーティー、仲間の加入と入れ替え、各仲間の能力である。現在のステージ5は、2フロアで仲間の能力を試すステージである。

各仲間は、自分の区間の入り口に立つコーチとして振る舞う。プレイヤーが近づくと自分の能力を自慢し、接触すると加入する。

仲間は最大2人で、3人目の加入時に最も早く加入した仲間が脱退する。以下の構成は、すべての仲間を順番に加入させた場合を示す。

## 進行と配置

1. **敵のパーティー**：同じ種類の敵を1体、次に縦に並んだ2体のパーティーとして配置する。1体には勝てるが、2体には敗北することを試す。1体目の撃破によるレベル上昇後も、この関係が成立するように調整する。
2. **K（騎士）**：加入後、同じ敵の2体パーティーを配置し、勝てることを試す。Kのレベルが攻撃力に加算されることを示す。仲間は **K**。
3. **R（ならず者）**：加入後に `g`、`X` を配置し、Rがこれらの正体を見破ることを示す。仲間は **K・R**。
4. **G（守護騎士）**：加入後に `b` を2体、その先にバリアの帯とまきびしの帯を配置する。バリアの追加ダメージは半分、まきびしのダメージは3分の1になる。仲間は **R・G**（Kが脱退）。
5. **H（ヒーラー）**：加入後に `b` を2体、その先に長い何もない通路を配置する。移動時のLP消費が半分になることを示す。仲間は **G・H**（Rが脱退）。
6. **D（ダンジョン探検家）**：加入後、隠し通路を発見して進み、落とし穴に落ちる。下の階の上り口から戻ることで、Dの能力を示す。仲間は **H・D**（Gが脱退）。
7. **J（ジェスター）**：加入前後に同じ種類・同じ数の敵パーティーを配置する。取得経験値を比較し、分配後の経験値が1.5倍になることを示す。加入前は **H・D**、加入後は **D・J**（Hが脱退）。

## バランスと進行上の要件

- チュートリアルなので、チェックポイントは置かない。敗北やLP切れも体験の一部とし、既存のリスポーン処理に任せる。
- Kは初期レベルが50で、そのレベルが攻撃力にそのまま加算される。2体パーティーの強さは、プレイヤーだけでは負け、Kがいれば勝てる範囲に収める。Kの経験値の分配人数は1.0人で、K在籍中はプレイヤーの取得経験値が半分になることも考慮する。
- Gの区間は、Gがいれば手前の `b` 2体を倒してLPを補給しなくてもぎりぎり通過でき、倒せば余裕を持って通過できるよう調整する。Gなしの場合にLPが尽きるバランスも候補とする。開始時のLPや、それまでの行動による差を考慮する。
- Hの区間は、Hなしでもぎりぎり通過でき、Hがいれば余裕を持って通過できるよう調整する。手前の `b` 2体はLP補給に使える。`b` を倒さない場合の通過可能性も含め、実際のLPと移動距離で検証する。
- Dがいないと先へ通り抜けられない構成にする。未発見の隠し通路は剣でも壊せるため、隠し通路だけでは条件を満たせない。落下後、Dが必要な上り口を通ることを進行条件とする。Dなしで落下して先へ進めなくなっても構わない。
- 上り口になるのは、上の階で崩落 `O` だったマスの真下だけで、Dがいる場合のみ見えて登れる。落とし穴は、必要なら壁で区切られた幅1の通路に置く。下の階では上り口を見つけ、上がった後に穴から移動して抜けるまでを体験できるようにする。
- `X` は `respawn_on_random_floor=True` のため、固定マップでの再出現先を確認する。
- J自身は経験値の分配人数に0.25人、Hは0.5人、Dは0人として数えられる。そのため、H・DからD・Jへの変更では、取得量の差にHの脱退とJの加入の両方が影響する。分配後の値とJの1.5倍補正は既存の表示で示される。例えば敵の経験値合計が2なら、H・Dでは `2 ÷ 1.5 ≒ 1.33`、D・Jでは `2 ÷ 1.25 × 1.5 = 2.4`。

## 仲間のセリフ

- 仲間は各区間の入り口に配置する。プレイヤーが仲間の上下左右の隣のマスに入るたびに、その仲間が自分の能力を自慢するセリフを言う。隣のマスどうしを行き来すれば何度でも聞ける。
- 仲間に接触すると加入する（現在の `stage5.recruit` の動作）。セリフと加入は別の操作とする。
- セリフは既存のメッセージ欄に表示し、プレイヤーが移動すると消す。
- セリフが出たら、Rが危険を見つけた時と同様に連続移動を止め、読み逃しを防ぐ。
- セリフは説明調にせず、次の区間の仕掛けと結び付けた自慢にする。セリフでは効果の数値を言わず、どの仕掛けに効くかだけを伝える。効果の大きさは、直後の区間で実際に確かめさせる。
- 判定はゲームの進行処理の側で行い、GUIとターミナルの双方で表示と消去を確認する。日本語の文面は `locales/ja.json` に追加する。

### セリフ案

メッセージ欄に1行で収まるよう、日本語は1行30字程度に抑える。英語は `locales` の原文として使う想定。仲間ごとに口調を変える（Kは面倒見がよい、Rは気軽、Gは自分の装備を誇る、Hは姉御肌、Dは頼もしい、Jは陽気）。

加入前の自慢（隣のマスに入った時）：

| 仲間 | 位置 | 日本語 | 英語 |
| --- | --- | --- | --- |
| K | 2体パーティーの区間の後 | 「二匹相手は流石にきついか？ 俺が腕を貸してやるよ」 | "Two at once is a bit much, huh? I'll lend you a hand." |
| R | `g`・`X` の手前 | 「たいていのトラップなら見抜けるよ」 | "I can see through most traps." |
| G | バリアとまきびしの帯の手前 | 「魔法を付与された盾でバリアにもトゲにも効果があるんだ」 | "My enchanted shield works against barriers and spikes alike." |
| H | 長い通路の手前 | 「長い道のりを行くならヒーラーを連れて行くことよ」 | "If you're going a long way, take a healer with you." |
| D | 隠し通路と落とし穴の手前 | 「洞窟の地理はお任せ。俺なら穴に落ちても登れる」 | "Leave the lay of the caves to me. Even if I fall through a hole, I can climb out." |
| J | 経験値を比べる2回目の戦闘の手前 | 「このダンスは経験値を増やす効果があるんだ」 | "This dance of mine makes you gain more experience." |

## 実装時の確認

- 固定マップの具体的な寸法、座標、敵の種類・強さ、LPの値は未決定。通しプレイで調整する。現在の区画生成（`stage5.py`）とは別に、固定マップを読み込む仕組みが必要になる。
- 既存のステージ5生成、両フロントエンド、リスポーン・落下・上り口・隠し通路との整合を確認する。
- README（英 `README.md`、日 `README-ja_JP.md`）のステージ5の説明は、訓練場としての内容に全面的に書き直す。開始時のメッセージも訓練場の雰囲気に合わせる。必要なテストを追加し、既存のテストスイートを実行する。

## 実装メモ

ステージ6の生成処理は維持し、ステージ5専用の固定マップとチュートリアル処理を追加する。

1. **固定マップと進行順**
   - `stage5.build_member_trial()` を固定配置の訓練場に置き換える。上階を右へ進む主通路、下階をDの落下・復帰用の区間とする。
   - 敵と仲間を上記の順に配置し、接触による加入と、3人目の加入時に最古参が脱退する既存の仕組みを使う。
   - チェックポイントは追加せず、敗北・LP切れ時は既存のリスポーン処理に任せる。
   - 固定マップが設定値や画面表示に収まることを確認する。ステージ6の `build()` には影響させない。
2. **区間ごとの調整**
   - 最初の敵は、1体撃破後のレベルを含めて、単独では2体に負け、K加入後は同じ2体に勝てるようにする。K在籍中の経験値分配も考慮する。
   - Rの直後に `g` と `X` を置く。`X` の再出現先はフロアがランダムに選ばれるため、上下階の出現候補を確認し、進行を妨げないようにする。
   - GとHの区間は、移動距離、地形ダメージ、LP消費、`b` の回復量を使って検証する。上記の「倒さない／倒す」「仲間あり／なし」の条件を満たすよう、開始LPを含めて調整する。
   - Dの区間は、隠し通路と落とし穴を配置し、落下先からDが必要な上り口を使わなければ先へ進めない構造にする。剣で隠し通路を壊した場合も確認する。
   - Jの前後に同じ敵パーティーを置き、H・DとD・Jそれぞれの経験値分配とJの補正を比較できるようにする。
3. **仲間のセリフ**
   - ステージ5で未加入の仲間の上下左右に移動したとき、既存のメッセージ欄に自慢のセリフを表示する。隣接マス間の移動でも繰り返し表示し、接触による加入とは分ける。
   - 表示時は連続移動を停止し、次の移動でセリフを消す。判定は共通のゲーム進行処理に置き、GUIとターミナルの両方で使う。
   - 英語の原文と `locales/ja.json` の日本語訳を追加し、両モードで表示幅と既存メッセージとの優先順位を確認する。
4. **検証と文書更新**
   - 固定配置と進行順、仲間の入れ替え、各区間の戦闘・LP条件、Dあり／なしの通過、`X` の再出現、セリフの再表示・消去・連続移動停止をテストする。ステージ6とリプレイへの影響も確認する。
   - ステージ5を通しでプレイして数値と距離を調整し、可能な環境ではGUIとターミナルの双方を確認する。
   - `README.md` と `README-ja_JP.md` のステージ5説明を訓練場向けに書き直し、開始メッセージも変更する。
   - 最後に `uv run -p .venv/bin/python pytest`、`uv run -p .venv/bin/python python -m compileall src`、`uv run -p .venv/bin/python python -c "import arlq"` を実行する。確認できなかった画面モードがあれば、その制約を明記する。
