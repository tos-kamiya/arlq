# ステージ5 仕様メモ

現時点の仕様。5フロア構成と強めのメンバー効果で、敵配置を含むバランスを調整中。

## 現在の5フロア版

- `--stage 5`またはステージ選択から起動する。初期レベル1。既存の迷路生成を使い、シードにより5フロアの地形と配置を生成する。
- 各階で壁に塞がれた部屋の数を変え、3階以降には短い壁の突起も加える。
- 全5職業、既存同行者、集団戦用の敵、バリア・落とし穴、`k`、`F'`＋`V'`を配置する。まきびし（`x`）は配置しない。
- 最終フロアの空き床の5%にバリアを散布する（ステージ4最終フロアは10%）。
- クリア条件は5階で救出したNobleを連れて1階へ戻ること。階段で往復でき、落とし穴では下のフロアへ落ちる。
- メンバーは文字B/H/R/K/D/Nで表示する。1名の場合は左後ろ。壁際でも表示用の位置として扱い、当たり判定や矢の遮断には使わない。
- 戦闘力は剣・毒を反映したプレイヤーの値を基準に加算する。Knightは戦闘力を2倍にする。毒の補正は既存同様に端数切り上げ。
- レベル減少の特殊効果は、集団全体の経験値を加算した後に適用する。LP報酬はパーティー内の最大値を適用し、既存の上限処理を行う。
- `F'`の宝箱解錠は目的達成の処理として扱い、パーティー内のアイテム・特殊効果持ちの制限では数えない。`V'`の報酬は通常Vと同じ（経験値1・LP8）、ボスパーティー撃破後は再出現しない。
- `V'`の再配置後にNobleを出現させる。未加入候補者は再配置しない。床・バリアの探索記録は消去するが、壁・階段の位置はマップに残す。移動先をFOV外には限定しない。
- `X`を倒してもステージ5ではまきびしを散布しない。
- ボス撃破で宝箱とミミックが現れる。宝箱の取得は任意。
- Rogueの警告ではターンとLPを消費せず、キーを押し直すと危険なマスへ進める。崩落起点の察知は今後の検討とする。下層への遷移に崩落を配置する。

### 深さに応じた敵配置

- `c`と`C`の基本出現数を全フロアで従来の1.5倍にする（端数は切り上げ）。2～5階の通常モンスターは、`w'`の数を除いて種類・強化ランク・基本出現数を共通にする。`w'`は2・3階に0体、4・5階に2体。通常パーティーの補充候補も共通にし、パーティー人数の抽選確率は階ごとに変える。
- フロア間には通常階段を2組配置し、Dangeon Scholar同行時に使える隠し階段を1組追加する。各組は可能な限り別の部屋区画に配置し、区画が重なる候補は複数回引き直す。
- 通常パーティー人数1～5体の抽選確率は、1階が55/25/15/5/0%、2階が30/35/25/10/0%、3階が20/30/30/15/5%、4階が10/20/30/25/15%、5階が5/15/25/30/25%。ボスは`W`と`V'`。
- プライム（`'`）付きのrank 2は、ボスの`W`・`V'`の組み合わせだけを例外として、単独で配置する。補充・再配置時もほかのモンスターと隣接させない。
- 壁際や通路内も配置対象。壁から離す処理は行わず、パーティーが通路を塞いでもよい。2～5階の`g`と`k`は単独パーティーにする。ゴーレムはほかの敵と隣接させず、2階の`k`もほかの敵と隣接させない。補充・再配置でもこの条件を保つ。
- 5職業の候補者は全員1階のどこかに配置する。既存同行者は各階に配置する。
- ステータスのメンバー一覧にはフロア番号を表示しない。

## パーティーメンバー

- エルフは登場しない。ダンジョンに人間のメンバー候補が散在する。
- 候補者はFOVに入ると職業が判明し、接触で加入する。
- メンバーはプレイヤー以外に最大2名。満員時はFIFOで先に加入した者がパーティーを離れ、元いたフロアのランダムな場所に戻る。
- 通常メンバーは脱退しても元いた1階のランダムな場所で再加入できる。
- 既存の同行者枠はそのまま保持し、人間のメンバー2名の枠とは別に扱う。
- 敗北時もメンバーは脱退せず、Nobleを含めてプレイヤーと同じ場所にリスポーンする。加入順は維持する。

### メンバーの追従表示案

- Jがプレイヤーのすぐ後ろを追従する既存の表示を基準に、メンバーは左後ろ・右後ろの斜め隣に表示する。
- 先に加入したメンバーを左後ろ、後から加入したメンバーを右後ろに表示する。
- 1名の場合の表示側、方向転換時や壁際での表示方法は未決定。
- 表示位置が当たり判定や矢の遮断に影響するかは、別途検討する。

| 職業 | 能力 |
| --- | --- |
| Bard | 分配後の経験値獲得量を3倍にする |
| Healer | 移動時のLP消費を半分にし、敗北時のLP消費を2にする |
| Rogue | 落とし穴・`k`の射線を発見し、ミミックを判別する。上下左右に隣接した`g`・`X`も判別する |
| Knight | 戦闘力を2倍にし、分配後の経験値獲得量を半分にする |
| Dangeon Scholar (`D`) | 隠し階段を表示して利用でき、ゴーレム撃破でできた壁をすり抜ける。壁はmarksmanの矢を遮る |

## モンスターのパーティー

- 上下左右につながったモンスター全体がパーティーを組む。斜めは含めない。別パーティーと斜めに隣接した場合は、`F'`と`V'`を除くモンスターを移動させる。
- 最大5体。配置・再出現・再配置などで超過した場合は、一部を取り除いて調整する。
- どの個体に接触しても集団全体と戦い、勝敗はパーティー単位で決まる。
- アイテムまたは特殊効果を持つ個体は、両者を合わせてパーティー内に最大1体。
- 各個体の表示は、判明済みなら本来の文字、未判明なら `?`。

### 集団戦の戦闘力と報酬

- 敵パーティーの戦闘力は、各モンスターの戦闘力（強化個体の補正を含む）の合計。
- 勝利時のLP報酬は、敵パーティー内で最も高いモンスターのLP報酬をプレイヤーに与える。LP上限の扱いは既存ルールに従う。
- 勝利時の経験値報酬は、各モンスターの経験値報酬の合計をプレイヤーと加入中のメンバーの人数で割り、加入中メンバーの補正を掛けてプレイヤーに与える。
- Bardは3倍、Knightは0.5倍。両者がいる場合は掛け合わせて分配値の1.5倍。
- Healer・Rogue・Dangeon Scholarは経験値報酬を変更しない。Nobleも報酬への補正はない。
- 敵パーティー内の経験値報酬をプレイヤー側の人数で分配し、分配分はプレイヤーが受け取る。

## Nobleの救出とクリア

- ステージの目的は、最終フロアのNobleを救出して帰還すること。
- 暫定ボスはステージ4と同じ強火龍（`F'`）とする。
- ボスパーティーにはボルテックス（`V'`）を必ず含め、`F'`と上下左右の連結で同じパーティーにする。配置調整で両者を取り除かない。
- `F'`自体にVの能力は付与せず、同伴する`V'`が再配置効果を担う。特殊効果持ちの枠は`V'`が使うため、他のアイテム・特殊効果持ちは加えない。
- `V'`は通常のVの局所的な効果範囲をフロア全体へ広げる。ボスパーティー撃破時に、そのフロア全体を対象に再配置する。
- `V'`の`'`は通常どおりランク2を表し、戦闘力は通常のVのレベル×3＋10とする。
- 再配置対象はVと同様のモンスター・既存の同行者・宝箱。加入中のメンバーとプレイヤーは対象外。未加入の人間の候補者を対象にするかは未決定。
- 床・バリアの探索記録を消す処理もVと同様にフロア全体へ適用する。壁・階段の位置は残す。再配置後も敵パーティーの人数・特殊個体数の制約を満たす。
- ボス撃破により、ボスの近くにNobleが出現する。
- ボス撃破により宝箱も出現する。取得は任意で、取得してもクリアにはならず、クリア条件にも含めない。
- Nobleは接触で加入し、能力はなく、メンバー枠を1つ使う。
- NobleもFIFOの加入順に並ぶが、脱退はできない。Nobleが脱退する交代は行えず、新規加入を断る。
- 救出後のメンバー交代は最大1回。
- Nobleを連れて最初のフロアへ到達するとクリア。

### FIFOの例

1. Bard → Healerの順に加入している。
2. Nobleを救出するとBardが脱退し、Healer → Nobleになる。
3. Knightを迎えるとHealerが脱退し、Noble → Knightになる。
4. 以後はNobleが脱退する順番なので、新規加入はできない。

## 能力案

経験値（レベル）・LPは内部で端数を保持し、ステータス欄では小数部分を切り捨てて表示する。

Bard 分配後の経験値獲得が3倍になる。

Healer 1移動あたりのLPの減少を1から0.5にする。
リスポーン時のLP減少を6から2にする。

Rogue 落とし穴の「O」に入ろうとする直前に「O」を表示し、移動とキーリピートを停止する。kの射線のマス目に入ろうとすると「-」または「|」を表示し、移動とキーリピートを停止する。ミミックの隣に来ると正体がわかる（Mの表示になる）。ゴーレムとカルトロッププラントの上下左右に隣接すると正体がわかる（`g`・`X`の表示になる）。

Knight プレイヤーと同じだけの戦闘力を加算する。Knightが単独でメンバーなら戦闘力2倍扱い。
分配後の経験値獲得量は半分になる。

Dangeon Scholar 隠し階段を表示して利用できる。ゴーレム撃破でできた壁を通り抜けられるが、marksmanの矢はその壁に遮られる。
