# ボーンから組み立てる主人公の甲冑

`hero-rig.blend` は人型の骨格を先に作り、各ボーンに独立した甲冑を取り付けた主人公のモデル。
剣（4種類）・マント・倒れた姿勢を含む。頭身を下げた版（`hero-rig-chibi.blend`、後述）が
ゲーム用のプレイヤー画像の元になる（`../build-heroic.py` が読み込む）。
リポジトリには `build.py`・`build-chibi.py` などのソースと `hero-rig-chibi.blend` だけを置く。
`hero-rig.blend` とポーズの画像（`rest.png` など）、`chibi-*.png`、`sprite-*.png` は
スクリプトで生成し、追跡しない（`.gitignore`）。

## 開く・ポーズを付ける

Blender で `hero-rig.blend` を開くと `Hero rig` が Pose Mode で選択される。
ボーンは甲冑の手前に表示する。ボーンを選び、`R` または Item パネルの
Rotation で回転させる。回転はボーンのローカル座標。
甲冑は Bone Parent で固定してあり、メッシュ自体は変形しない。
移動と拡縮は root 以外ロックし、関節の位置を保つ。

| 関節 | ボーン | 自由度 |
| --- | --- | --- |
| 首 | `neck`（兜は子の `head` に固定） | 3軸回転 |
| 肩 | `upper_arm.L` / `.R` | 3軸回転 |
| 肘 | `forearm.L` / `.R` | ローカルX、0〜145度 |
| 腰 | `waist` | 3軸回転。ローカルYで上半身をひねる |
| 脚の付け根 | `thigh.L` / `.R` | 3軸回転 |
| 膝 | `shin.L` / `.R` | ローカルX、−145〜0度 |
| 手首・足首 | `hand.L` / `.R`、`foot.L` / `.R` | 3軸回転 |
| マント | `cape.L.1`〜`.4`、`cape.C.*`、`cape.R.*` | 3軸回転。左・中央・右の鎖で布を曲げる |
| 腰の斜め前の下板 | `hip_plate.L` / `.R` | 自動。太もものローカルX回転を前方向（0〜90度）だけコピー |

`L` は本人の左。Z が上、−Y が正面。鎖骨・胸・頭も独立ボーン。
肘と膝には Limit Rotation を設定し、他の2軸を固定している。
肩当ては上腕、肘当ては前腕、膝当てはすねに追従する。
肩当て・肘当て・膝当ては丸みのある黒っぽい金属製。
肘当てと膝当ては、曲がる内側の幅を狭く、外側を広くした形状。
肩当ては胸側の側面を切り欠いた中空の外装で、腕の付け根が入る余地を設けている。
肘当てと膝当ても中空の殻で、曲がる軸の内側（肘は前、膝は後ろ）が開いている。
開口部に向かって帯の幅が楕円状に狭まり、端は脚や腕に寄せて丸く閉じる。
兜は heroic の主人公と同じく、天面が平らで側面が立った角の丸い箱形。縦の角と上下の縁は
大きめに丸めている（断面の超楕円の指数0.575）。靴も同じ断面の角の丸い箱形で、黒い鉄製。
覗き窓は兜から横長の棒（`Eye slot cutter`、レンダリングでは非表示）をブーリアンで
引いた溝で、横から見ても前の角に切り込みが見える。溝の内側は黒い鉄で、奥の
一回り小さい水色に光る窓の周りが黒い縁になる。棒を動かすと溝の位置や大きさを変えられる。
兜は中空で、内側は暗い内張り。兜と同じ断面から壁の厚さ（側面1.8cm・後ろ1cm・前3.5cm）を
差し引いた空洞（`Helmet cavity cutter`）を下から引いている。後頭部の下端は、左右に通した丸い棒
（`Nape cutter`、半径5cm、`NAPE_CUT_CENTER`・`NAPE_CUT_RADIUS`）で削り、首の後ろが空洞へ開く。
どちらの棒もレンダリングでは非表示で、動かすと形を変えられる。
兜には heroic の主人公と同じ、黒い鉄のとさかと角を付けている（`head` に固定）。
とさかは薄い三角の板で、頭頂から覗き窓の先へ前上がりに反る。角は四角錐で、
兜の側面から外・後ろ・上へ伸びる。heroic の頭の寸法を0.8倍して合わせたうえで、
とさかは土台の中心を基準にさらに0.8倍、角は1.08倍にして左右を90%に寄せ、1cm上げている。
丸めた兜の角は角の四角い付け根の下で内側へ逃げるため、角を軸に沿って兜の中へ6cm延ばし、
見える部分の形を変えずに付け根を埋めている。
胸甲は腹部まで伸ばし、正面の下端は中央が少し下がる浅いV字にしている。
幅と厚みは心臓の高さ（z 1.30）で最大になり、肩に向かってゆるやかに細くなる。
背中には heroic の主人公と同じ深い紺のマントを付けている。マントだけは鎧の板と違ってボーンで曲がる布で、
左・中央・右の3本の鎖（各4本、根元は `chest`）に滑らかなウェイトで追従する（Armature モディファイア）。
上端は首の鎖帷子の高さで首の後ろを包み、肩の後ろを越えて（角は肩当ての下）膝上まで下がり、
背中を回り込んで裾へ少し広がる。縦のひだが6本あり、上端では平らで裾で約2cmの深さになる。サンプルの構えと一歩では
裾を後ろへなびかせている。布のシミュレーションはないので、なびきはボーンを回して付ける。
首には黒い鎖帷子の首当て（`Gorget`）を付けている（`chest` に固定）。胸甲の上端から立ち上がる
低い円錐で、首に向かって細くなり、黒い鉄の丸棒の縁から垂れる。腰の鎖帷子と同じ材質で、
寸法は `GORGET_SCALE`（高さと広がり）と `GORGET_RADIUS`（首への締まり）で調整できる。
首当ては胸に固定なので、`neck`・`head` で20度ほどうなずく・かしげると兜の下端が上端に当たる
（ひねりは45度まで当たらない）。
胸甲には heroic の主人公と同じく、黒い鉄の細い丸棒の輪を2本巻いている（`chest` に固定）。
輪は胸甲の12角の断面に沿い、半分ほど埋まる。高さはベルトから肩までの比率を heroic に合わせた。
腰甲の上部、胸甲の裾の下に黒い鉄の平たいベルト（幅約4.5cm）を巻いている。
上ほど細い腰甲の傾きに沿って密着し、正面に黒い鉄の四角い板のバックルを付けている。
ベルトは骨盤に固定。
左右の斜め前には、このベルトから下げた黒い鉄の鎖帷子を追加している。
鎖帷子の上端はベルトの芯の位置にあり、ベルトの内側から垂れて見える。
輪が互い違いに重なる模様は、UV 上のノード計算による凹凸と色で表している。
正面から左右50度の位置を中心に側面へ回り込む。周方向の幅は、ベルトから z 0.853 までは
22.7cm の長方形で、裾で19.4cmに狭まる。ベルトから z 0.975 までは腰甲の表面から1.5cm外に
沿って下り、ベルトの所で横に張り出さない（剣の鞘を下げる余地を残す）。そこから裾へなだらかに広がる。
鎖帷子は上下2枚に分かれる。上の帯は骨盤に固定し、下の板は上の帯の内側に
上端を差し込み、`hip_plate` ボーンで上端を軸に回る。太ももを前に上げると
同じ角度だけ前に振れ、後ろに引いたときは垂れたまま動かない。
腰の金色のリングは設けず、腰甲の上端をその高さまで伸ばしている。
腰甲の下端はブリーフ型で、前後の中央は股（z 0.82）まで下がって太ももの間で細くなり、
左右は脚の付け根の高さに残って脚の出口が弧を描く。断面を32角にして、股を丸いU字にしている。
太ももを前に45度までは鎖帷子に当たらず、約60度から下の板が太ももの板・腰甲・ベルトに当たる。
下の板の脇の端は、太ももを前に約30度以上上げると股関節の暗い球にわずかに入り込む。

| --- | --- | --- |
| 1 | 基準の立ち姿 | `rest.png` |
| 40 | 腰と首をひねり、両肘を曲げた構え | `guard.png` |

サンプルには回転のキーフレームがある。編集したポーズを残すには回転の
キーフレームを挿入して保存する。自由な静止ポーズだけを作る場合は
Object Mode の Object > Animation > Clear Animation でサンプルを外してから編集する。
これはFK（関節を直接回す方式）の試作で、足の接地を保つIKや装甲同士の
衝突補正はない。歩行サンプルは完成した歩行アニメーションではない。

## 剣・籠手・倒れた姿勢

右手（`hand.R`）に heroic の主人公と同じ4種類の剣を持たせる。1つだけを表示し、ほかは隠しておく。

| 剣 | 部品名 | 形・材質 |
| --- | --- | --- |
| 自分の剣 | `Sword …` | 幅広の短剣、灰色の鉄。刃先を左上へ立て、さらに後ろへ0.2ラジアン倒し、長さの軸まわりに0.2ラジアン回す（`SWORD_BACK_TILT`、`SWORD_ROLL`） |
| キメラの剣（c） | `Chimera sword …` | 三角の平たい刃、青白く光る鋼、金の鍔と柄頭。低く左下へ向ける |
| 呪いの剣（C） | `Cursed sword …` | キメラの剣と同じ形。黒い鋼が赤く光り、柄は灰色の鉄 |
| Kの加護 | `Blessed sword …` | 自分の剣と同じ形・構え。刃が青く光る |

拳は heroic と同じく黒い鉄の丸い籠手（`Gauntlet L` / `R`）。
倒れた姿勢（フレーム120）はうつ伏せで頭を画面の右下へ向け、顔をカメラ側へ55度向け、
頭と首を後ろへ傾けて胸を床に着け、右腕を頭の先へ投げ出す。覗き窓はこのフレームだけ暗くする。
床への接地と中央寄せは組み立て時に計算する（剣・マント・腰の鎖帷子は除く）。
マントはこのフレームだけ、鎧と床をボクセルで包んだなめらかな面（非表示の `Cape drape target`）へ
真下に投影して体にかける。落とす量は全体で0.3、脚の間で0.2（`DRAPE_AMOUNT`、
`DRAPE_AMOUNT_BETWEEN_LEGS`）。マントの形は、裾へ行くほど後ろと体の左へ流れる（heroic のマントの半分の量、
`CAPE_DRIFT_BACK`、`CAPE_DRIFT_SIDE`）。

## 頭身を下げた版とスプライト

```bash
blender --background --threads 4 --python dev-samples/3d-stage1/rigged-armor/build-chibi.py
blender --background --threads 4 --python dev-samples/3d-stage1/rigged-armor/render-chibi-sprites.py [-- --sword chimera|cursed|blessed]
```

`build-chibi.py` は同じモデルを組み立て、頭はそのままに胴0.6・腕0.55・脚0.46倍（各ボーンの長さ方向）へ縮め、
断面方向はその1.2倍に太らせて約4頭身にする（`hero-rig-chibi.blend` と `chibi-*.png`）。
鎖骨は長さ方向も太らせて肩幅を合わせ、マントは胸と同じ縮め方にする。丸い部品（関節の球・肘当て・膝当て・
肩当て・籠手）と剣は縦横同じ倍率で縮めて形を保つ。斜めのボーンを太らせるとせん断になるため、
部品の変形はメッシュへ焼き込む。組み立てにはマントの包み面を作るため約3分かかる。

`sprite_pose.py` はスプライト用のポーズを付ける。向き（下・左・右・上）に回したあと、足元を中心に体を
0.1ラジアン、首でさらに頭を0.3ラジアン後ろへ傾け（`BODY_LEAN`、`HEAD_TILT`）、評価済みのメッシュを複製して焼く
（リグは変えない）。倒れた姿は傾けず剣も持たせない。`render-chibi-sprites.py` はこれで60度の見下ろしの
確認画像（`sprite-<ポーズ>-<向き>.png`）を描く。`../build-heroic.py` は同じ処理でプレイヤーを heroic の
シーンに置き、heroic の以前のプレイヤーと同じ高さ（`HEROIC_PLAYER_HEIGHT`）にそろえる。
ゲーム用画像の再生成手順は `../README.md` の「キャラクター素材の再生成」を参照。

## 再生成と構造変更

```bash
blender --background --threads 4 --python dev-samples/3d-stage1/rigged-armor/build.py
```

同じディレクトリに `hero-rig.blend` と4枚の画像を生成する（追跡しない）。手編集したモデルは
別名保存する。Blender 4.0.2 で確認。

- `BONES`: 関節位置と親子関係。ここで骨格・体格を決める。
- `build_armor()`: ボーン座標に沿って甲冑を追加する。
- `plate()`: ボーン始点からの距離・幅・厚みを指定して板金形状を作る。
- `POSES`: ボーンごとの回転角（度）。首と腰は第3成分をひねりとしてローカルYに変換。
- `validate()`: 必須10関節の回転でパーツが実際に追従し、体積スケールが変化しないことを検証する。
- `material()` / `setup_scene()`: 質感と照明。`../heroic/preview-player-facings.jpg` の
  主人公（`../build-heroic.py`）に合わせ、青みの鋼（縁がほのかに光る）、兜・脚用の鋼、
  黒い鉄の肩・肘・膝当てと靴、水色に光る覗き窓を使う。夜のスタジオの背景・床、
  暖色のキー・寒色のフィル・左右の逆光、Medium High Contrast の色調も同じ。

自動ウェイトは使わず、金属部分を硬い部品として扱う。首や肘・膝には暗色の
関節部品を置き、外装の間に曲げる余地を設けている。大きな角度での装甲干渉は
今後の形状調整が必要。
