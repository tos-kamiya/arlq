# ボーンから組み立てる主人公の甲冑

`hero-rig.blend` は人型の骨格を先に作り、各ボーンに独立した甲冑を取り付けた試作。
既存の `heroic/`、`armor-prototype/` とゲーム用スプライトは変更しない。
外観は関節の構造を確認するための新規モデルで、剣・マントはまだ含まない。

## 開く・ポーズを付ける

Blender で `hero-rig.blend` を開くと `Hero rig` が Pose Mode で選択される。
ボーンは甲冑の手前に表示する。ボーンを選び、`R` または Item パネルの
Rotation で回転させる。回転はボーンのローカル座標。
甲冑は Bone Parent で固定してあり、メッシュ自体は変形しない。
移動と拡縮は root 以外ロックし、関節の位置を保つ。

| 関節 | ボーン | 自由度 |
| --- | --- | --- |
| 首 | `neck`（兜は子の `head` に固定） | 3軸回転 |
| 肩 | `upper_arm.L` / `.R` | 3軸回転 |
| 肘 | `forearm.L` / `.R` | ローカルX、0〜145度 |
| 腰 | `waist` | 3軸回転。ローカルYで上半身をひねる |
| 脚の付け根 | `thigh.L` / `.R` | 3軸回転 |
| 膝 | `shin.L` / `.R` | ローカルX、−145〜0度 |
| 手首・足首 | `hand.L` / `.R`、`foot.L` / `.R` | 3軸回転 |
| 腰の斜め前の下板 | `hip_plate.L` / `.R` | 自動。太もものローカルX回転を前方向（0〜90度）だけコピー |

`L` は本人の左。Z が上、−Y が正面。鎖骨・胸・頭も独立ボーン。
肘と膝には Limit Rotation を設定し、他の2軸を固定している。
肩当ては上腕、肘当ては前腕、膝当てはすね、腿当ては左右の太ももに追従する。
腿当ては太ももの板に沿う開いた殻で、内股側を空け、上端は腰甲の内側から始まる。
肩当て・肘当て・膝当ては丸みのある黒っぽい金属製。
肘当てと膝当ては、曲がる内側の幅を狭く、外側を広くした形状。
肩当ては胸側の側面を切り欠いた中空の外装で、腕の付け根が入る余地を設けている。
胸甲は腹部まで伸ばし、正面の下端は中央が少し下がる浅いV字にしている。
左右の斜め前には、骨盤から下げた湾曲プレートを追加している。
正面から左右50度の位置を中心に側面へ回り込み、中央を広く空けた形状。
プレートは上下2枚に分かれる。上の帯は骨盤に固定し、下の板は上の帯の内側に
上端を差し込み、`hip_plate` ボーンで上端を軸に回る。太ももを前に上げると
同じ角度だけ前に振れ、後ろに引いたときは垂れたまま動かない。
腰の金色のリングは設けず、腰甲の上端をその高さまで伸ばしている。
太ももを前に約60度以上上げると、下の板と腿当てが干渉する。

タイムラインのマーカーでサンプルのポーズを選べる。

| フレーム | ポーズ | 画像 |
| --- | --- | --- |
| 1 | 基準の立ち姿 | `rest.png` |
| 40 | 腰と首をひねり、両肘を曲げた構え | `guard.png` |
| 80 | 股関節・膝・肩を動かした一歩 | `step.png` |

サンプルには回転のキーフレームがある。編集したポーズを残すには回転の
キーフレームを挿入して保存する。自由な静止ポーズだけを作る場合は
Object Mode の Object > Animation > Clear Animation でサンプルを外してから編集する。
これはFK（関節を直接回す方式）の試作で、足の接地を保つIKや装甲同士の
衝突補正はない。歩行サンプルは完成した歩行アニメーションではない。

## 再生成と構造変更

```bash
blender --background --threads 4 --python dev-samples/3d-stage1/rigged-armor/build.py
```

同じディレクトリの `.blend` と3枚の画像を再生成するため、手編集したモデルは
別名保存する。Blender 4.0.2 で確認。

- `BONES`: 関節位置と親子関係。ここで骨格・体格を決める。
- `build_armor()`: ボーン座標に沿って甲冑を追加する。
- `plate()`: ボーン始点からの距離・幅・厚みを指定して板金形状を作る。
- `POSES`: ボーンごとの回転角（度）。首と腰は第3成分をひねりとしてローカルYに変換。
- `validate()`: 必須10関節の回転でパーツが実際に追従し、体積スケールが変化しないことを検証する。

自動ウェイトは使わず、金属部分を硬い部品として扱う。首や肘・膝には暗色の
関節部品を置き、外装の間に曲げる余地を設けている。大きな角度での装甲干渉は
今後の形状調整が必要。
