# Stage 5 / ステージ5

## English

Stage 5 is an experimental four-floor copy of the original Stage 4, preserved
while Stage 4 expands to five floors. It keeps the original floor layout,
monster roster, stairs, and traps. As in the other multi-floor stages,
discovering a stair marks its matching cell on the adjacent floor as explored.
Start with `--dev` to select it from the stage menu, or use `--stage 5` directly.

See [Stage 4](stage4.md) for the current gameplay description. Stage 5's design
for a future five-floor version is tracked in
[`stage4-five-floor-handoff.md`](stage4-five-floor-handoff.md).

## 日本語

ステージ5は、ステージ4を5フロアに拡張する前の4フロア版を保存した実験用コピーです。
元のフロア配置、モンスターのロスター、階段、トラップを維持します。他の複数フロアの
ステージと同様に、階段を発見すると隣接フロアの対応セルも探索済みになります。`--dev`で
ステージ選択メニューに表示するか、`--stage 5`で直接開始できます。

現在のゲーム内容は[ステージ4](stage4.md)を参照してください。将来の5フロア版の
設計は[`stage4-five-floor-handoff.md`](stage4-five-floor-handoff.md)で管理します。
